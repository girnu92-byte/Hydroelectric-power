ACADEMY

Variables

Caudal (Q): volumen de agua por segundo; 1 L/s = 0,001 m³/s.
Altura neta (H): desnivel útil tras descontar pérdidas de carga.
Eficiencia (η): fracción de potencia hidráulica que se vuelve eléctrica (turbina, generador, transmisión).
Tiempo (t): horas de operación; multiplica la potencia para dar energía.
Demanda: potencia que se desea abastecer.

Conceptos

Potencia hidráulica es la que lleva el agua: ρ·g·Q·H. Potencia eléctrica es lo que entrega el generador: Ph·η, siempre menor. Pérdidas de carga: la fricción en tubería y accesorios reduce la altura bruta; la altura neta ya las incluye. Eficiencia: con η = 70 %, de cada 100 W hidráulicos se obtienen 70 W eléctricos.

Reto

«Si el caudal aumenta al doble y las demás variables permanecen constantes, ¿qué sucede con la potencia eléctrica?»

Proyecto y guía académica

Problema y modelo

Estimar la potencia y la energía de una microcentral a partir del caudal, la altura neta y la eficiencia, y compararlas con una demanda. Sistema: embalse → tubería forzada → turbina → generador → carga.

Pseudocódigo

INICIO
 LEER Q, unidad, H, eta%, t, D
 SI dato vacío/no numérico/no finito → ERROR
 SI Q≤0 o H≤0 o eta≤0 o eta>100 o t≤0 o D<0 → ERROR
 SI unidad = L/s ENTONCES Q ← Q/1000
 Ph ← 1000×9,81×Q×H
 Pe ← Ph×(eta/100)
 E ← (Pe/1000)×t
 SI D = 0 → «sin demanda»
 SINO cob ← Pe/1000/D×100
   SI cob≥100 «cubre»; SINO SI cob≥50 «parcial»; SINO «insuficiente»
 PARA i ← 0 HASTA 20: P(Q·f), P(H·f), f = 0,2+0,09·i
 MOSTRAR resultados
